## Retained UI correction — Applications topology

The current Applications tree is misleading at presentation level.

The required visual model is:

- one parent **OWASYS** card;
- inside that card, exactly two internal sub-cards: **owasys-front** and **owasys-back**;
- generated applications such as **essai** are displayed outside this internal OWASYS composition, in a distinct generated-applications area/list connected semantically to OWASYS as applications generated/managed by OWASYS;
- a generated application must never appear as a third sibling component alongside `owasys-front` and `owasys-back` under the OWASYS internal architecture;
- the correction is currently classified as a SCORE/presentation clarity issue, not as a registry/business-model change unless source review later proves otherwise.

Target reading of the screen:

`OWASYS = owasys-front + owasys-back`

and separately:

`Applications generated by OWASYS = essai, ...`

This UI action is retained in the remaining P117W work and must be addressed in a later bounded deliverable without displacing the current R8B7I runtime-performance acceptance gate.
